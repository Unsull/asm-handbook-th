# บทที่ 08 — Remediation

> แก้ช่องโหว่และพิสูจน์ผลการแก้ไข

บทนี้เป็นหนึ่งในชุดคู่มือเรียนรู้ ASM ภาษาไทยที่เขียนใหม่โดยอิสระ โดยใช้ลำดับหัวข้อที่ตรวจสอบกับ [สารบัญของ O’Reilly](https://www.oreilly.com/library/view/attack-surface-management/9781098165079/ch08.html) และขยายความด้วยแนวปฏิบัติจากเอกสารมาตรฐานและกรณีศึกษาสมมติ

## หัวข้อหลักจากสารบัญต้นฉบับ

- Assessing the Remediation Need
- Prioritization of Findings

- Validation of Remediation Efforts

## วิธีเรียนบทนี้

1. เริ่มจาก **แนวคิดเชิงลึก** โดยพยายามอธิบายศัพท์ใหม่ด้วยตัวเอง
2. ใช้ **กรณีศึกษา** เพื่อแยกข้อค้นพบจริงออกจากสมมติฐาน
3. ทำ **Workshop** กับระบบจำลองหรือระบบที่ได้รับอนุญาตเท่านั้น
4. ทำ **แบบทดสอบ** ท้ายบทแล้วทบทวนข้อที่ไม่เข้าใจ

> **ขอบเขต:** ตัวอย่างทั้งหมดเป็นสถานการณ์สมมติ ไม่ใช่รายงานช่องโหว่ของธุรกิจหรือบริการจริง

## เรียนจากระบบที่พบได้ทั่วไป

ใช้กรณีศึกษาร้านค้าออนไลน์ ระบบจองห้องพัก ระบบสมาชิก Cloud Services และ IoT แทนการผูกการเรียนกับโปรเจกต์เฉพาะแห่ง

::: info ที่มาของโครงเรียน
เนื้อหาเขียนขึ้นใหม่เป็นคู่มืออิสระ โดยใช้ลำดับหัวข้อของหนังสือ *Attack Surface Management* (Ron Eddings & MJ Kaufmann, O'Reilly, 2025) เพื่อวางโครงการเรียนรู้ ไม่ใช่คำแปลอย่างเป็นทางการ และไม่ใช่เนื้อหาแทนหนังสือต้นฉบับ
:::

# แผนการเรียน 11 บท

ลำดับหัวข้อหลักสอดคล้องกับสารบัญสาธารณะของหนังสือ *Attack Surface Management* (2025) แต่คำอธิบาย Workshop และตัวอย่างเป็นเนื้อหาที่เขียนขึ้นใหม่เพื่อการศึกษา

| บท | แนวคิดที่เรียน | ลิงก์ |
|---|---|---|
| 01 | พื้นฐานและวงจรการจัดการ Attack Surface | [เข้าสู่บทที่ 01](/chapters/01-foundations/) |
| 02 | ประเภท Attack Surface และขอบเขตความเชื่อถือ | [เข้าสู่บทที่ 02](/chapters/02-types-of-surfaces/) |
| 03 | จาก Exposure สู่การประเมินความเสี่ยง | [เข้าสู่บทที่ 03](/chapters/03-risk/) |
| 04 | ค้นหา จัดประเภท และเพิ่มบริบทของสินทรัพย์ | [เข้าสู่บทที่ 04](/chapters/04-asset-identification/) |
| 05 | ค้นหาและติดตามสินทรัพย์โดยอัตโนมัติ | [เข้าสู่บทที่ 05](/chapters/05-automated-discovery/) |
| 06 | รู้จักสินทรัพย์สำคัญและตัดสินใจจัดลำดับ | [เข้าสู่บทที่ 06](/chapters/06-prioritization/) |
| 07 | วิเคราะห์ Data Flow, Trust Boundary และ Threats | [เข้าสู่บทที่ 07](/chapters/07-attack-surface-analysis/) |
| 08 | แก้ช่องโหว่และพิสูจน์ผลการแก้ไข | [เข้าสู่บทที่ 08](/chapters/08-remediation/) |
| 09 | ลดช่องทางที่ไม่จำเป็น โดยไม่ทำลาย Business Workflow | [เข้าสู่บทที่ 09](/chapters/09-minimization/) |
| 10 | Monitoring, Alerting และ Incident Response | [เข้าสู่บทที่ 10](/chapters/10-monitoring/) |
| 11 | AI/ML, Quantum, Edge และการปรับตัวระยะยาว | [เข้าสู่บทที่ 11](/chapters/11-future/) |

## อ่านแบบตามระดับ

**เริ่มต้น:** บท 1–3 เพื่อแยก Asset, Exposure, Risk และตั้งสมมติฐานที่ตรวจสอบได้

**สำรวจระบบ:** บท 4–5 เพื่อทำ Inventory และ Discovery อย่างปลอดภัย

**วิเคราะห์และแก้ไข:** บท 6–9 เพื่อจัดลำดับ Crown Jewels, Threat Modeling, Remediation และลด Exposure

**ทำงานต่อเนื่อง:** บท 10–11 เพื่อทำ Monitoring, Incident Response และเตรียมรับเทคโนโลยีใหม่

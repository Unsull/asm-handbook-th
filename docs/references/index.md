## วิธีใช้อ้างอิงอย่างมีวิจารณญาณ

เอกสาร Software/Framework เปลี่ยนตาม Version; ควรบันทึกวันที่เข้าถึงและตรวจ Version เมื่อปฏิบัติจริง ตัวอย่างในคู่มือใช้แหล่งมาตรฐานและแนวทางที่เปิดเผยสาธารณะ และมีคำอธิบายเชิงการสอนโดยไม่อ้างว่าระบบสมมติมีช่องโหว่ที่ตรวจพบแล้ว
